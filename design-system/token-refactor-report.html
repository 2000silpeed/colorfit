What Changed

  • Flat 토큰 나열 → Core(원재료) / Semantic(역할) / Component(shadcn) 3계층 구조
  • Color scale 도입: neutral 12단계, accent 7단계, feedback 4종
  • Spacing scale 확장: 12px, 96px 추가 (하네스 권장 스케일 적용)
  • Radius에 pill(9999px) 추가, none(0px) 추가
  • Motion 토큰 신규: 6단계 duration + 4종 easing curve
  • Elevation 토큰 신규: flat / raised / overlay / modal 4단계
  • shadcn 토큰이 semantic 토큰을 참조 → 한 곳만 바꾸면 전체 전파
  • backward compat alias 유지 → 기존 코드 깨지지 않음
  • Dark mode: core 레이어만 오버라이드 → semantic/component 자동 적용

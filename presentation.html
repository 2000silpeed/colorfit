코디 조합 생성 알고리즘

레시피 기반 생성

단순 랜덤 조합이 아닌, TPO×무드×성별 레시피로 의도적 코디 설계

예시: 여성 출근룩 미니멀 레시피

필수: 블라우스/셔츠 + 슬랙스/스커트 + 로퍼/펌프스

선택: 재킷, 가방, 시계

금지: 후드, 스니커즈, 백팩

포멀도: 3~5 (캐주얼~포멀)

생성 규칙

  • 포멀도 편차 ≤ 2 (후드+정장바지 방지)
  • 가격 비율 3배 이내 (100만원 코트 + 5천원 양말 방지)
  • 색상 다양성 max_dist ≥ 40 (올블랙 방지)
  • 최소 3피스 (신발 필수)

Hard Filter — 8단계 탈락 필터

단계 필터명 탈락 조건 설계 근거 비용
H1 성별 불일치 코디 성별 ≠ 사용자 성별 (unisex 허용) 기본 매칭 O(1)
H2 예산 초과 코디 총액 > 예산 상한 예산 초과는 추천 무의미 O(1)
H3 계절 불일치 현재 월의 반대 시즌 (여름↔겨울) 인접 시즌은 허용 O(1)
H4 TPO 불일치 동의어 확장 후에도 매칭 0 commute↔office 확장 O(n)
H5 브랜드 미인증 153개 화이트리스트에 1개도 없음 신뢰도 확보 O(n)
H7 톤 호환성 사용자 톤 + 호환 톤에 매칭 0 P1 원칙: 필터율 30% 상한 O(n)
H8 StyleFilter SF 55점 미만 후드+정장 등 명백한 부조화 O(n²)
H6 LLM 품질 Gemini 3점 미만 규칙으로 못 잡는 부조화 Pre

비용 순서로 적용 — 무료 필터(H1~H5) 먼저 실행하여 후속 비싼 필터의 입력 크기를 줄인다.
